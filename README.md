# 🛒 Simple E-Commerce Store

A Simple E-Commerce Store built using **Node.js, Express.js, MongoDB, EJS, HTML, CSS, and JavaScript**. This project allows users to browse products, add products to the cart, place orders, and provides an admin panel to manage products and orders.

---

## 📌 Features

### User Features

* User Registration
* User Login
* View Products
* Product Details
* Add to Cart
* Remove from Cart
* Checkout
* Place Orders
* View Order History

### Admin Features

* Admin Login
* Add Products
* Edit Products
* Delete Products
* View All Users
* View All Orders
* Manage Product Images

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/siddiquelodhi777-png/simple-ecommerce-store.git
```

2. Open the project folder

```bash
cd simple-ecommerce-store
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file and add:

```env
MONGO_URI=mongodb://127.0.0.1:27017/ecommerce
PORT=3000
```

5. Start the server

```bash
npm run dev
```

6. Open your browser

```text
http://localhost:3000
```
